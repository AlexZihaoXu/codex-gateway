# Product

## Register

product

## Users

Developers running Codex Gateway on a trusted local machine. They connect OpenAI-compatible tools and projects, manage project API keys and limits, inspect usage, and troubleshoot compatibility without exposing the gateway publicly.

## Product Purpose

Codex Gateway provides a dependable local OpenAI-compatible interface backed by an authenticated Codex account. Success means one-command startup, familiar API contracts, clear operational status, safe project-level controls, and documentation that developers can use without additional setup.

## Brand Personality

Modern, precise, trustworthy. The product should feel like mature developer infrastructure: calm under load, explicit about state, and economical with attention.

## Anti-references

Avoid flashy AI branding, neon cyberpunk styling, generic SaaS card walls, decorative glass effects, hidden behavior, and novel controls where established developer-tool conventions are clearer. API documentation should retain the scanability and direct manipulation developers expect from Swagger UI without looking like an unrelated third-party page.

## Design Principles

- Prefer familiar developer workflows over novelty.
- Make system state, limits, and failure modes explicit.
- Keep common actions fast and advanced detail progressively available.
- Preserve a coherent Codex Gateway identity across dashboard and documentation.
- Earn trust through consistency, accessibility, and restrained presentation.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Support keyboard navigation, visible focus, reduced motion, sufficient contrast, and status communication that never relies on color alone.
